CARA KERJA

Logika di balik keputusan.

Data dipisahkan dari logika keputusan supaya bisa diaudit, diperbarui, dan dibacktest tanpa mengubah UI.

01

Koreksi

Jarak harga sekarang dari peak memberi konteks seberapa dalam penurunan sudah terjadi.

02

Momentum

Perubahan berbasis tanggal aktual; tidak menganggap snapshot ke-5 sama dengan 5 hari.

03

Tren

Perubahan jangka panjang memberi konteks apakah koreksi muncul di dalam tren yang lebih besar.

04

Spread

Selisih jual dan buyback adalah hambatan awal sebelum posisi mendekati impas.

05

Alokasi

Score diterjemahkan menjadi porsi awal supaya strategi tidak all-in.

06

Confidence

Confidence mengukur kelengkapan observasi, bukan probabilitas harga naik.

SUMBER & ETIKA

Catatan data

Sumber harga: halaman publik Galeri24. Gold Advisor hanya menyimpan data harga 1 gram dan buyback yang dibaca dari halaman tersebut.

Frekuensi collector: maksimal sekali per hari. Jika parser tidak yakin, data tidak ditulis.

Privasi: tidak mengambil akun, login, identitas pelanggan, atau data transaksi pribadi.

Catatan: ini alat bantu informasi pribadi, bukan aplikasi resmi Galeri24/Pegadaian dan bukan jaminan hasil investasi.

Arsitektur: GitHub menjadi rumah source code + Pages + scheduler; dataset disimpan sebagai versi JSON sampai volume data menuntut database terpisah.

Gold Advisor · alat bantu informasi untuk membaca timing akumulasi emas.
